## Go2 ports

| Interface | Connector | Location | Use |
|---|---|---|---|
| 28.8 V DC output | XT30 | Back | Payload or expansion-dock power |
| SBUS | SBUS socket | Back | RC/control signal |
| Ethernet | RJ45 | Back | Wired Go2 network access |

## Orin expansion dock ports

| Interface | Connector | Location | Use |
|---|---|---|---|
| USB 3.2 Gen 2 host, 5 V/1 A | USB-A | User I/O side | USB peripheral |
| 12 V/3 A output | XT30U-F → XT30U-M plug | User I/O side | 12 V accessory power |
| 5 V/3 A output | XT30U-F → XT30U-M plug | User I/O side | 5 V accessory power |
| Gigabit Ethernet | RJ45 | User I/O side | Laptop or external network |
| USB 3.2 + DP 1.4, 5 V/3 A | USB-C | User I/O side | USB peripheral or display |
| Forced reset | Recessed button | User I/O side | Hardware reset |
| Accessory Ethernet | GH1.25 4-pin | Go2/payload side | Accessory or robot arm |
| Gigabit Ethernet + 12 V/2 A | M8 | Go2/payload side | Powered radar |
| 16–45 V input ×2 | XT30U-F → XT30U-M plug | Go2/payload side | Dock and payload power input |
| Gigabit Ethernet | RJ45 | Go2/payload side | Connection to Go2 |
| USB 3.2 data, 5 V/2 A | USB-C | Go2/payload side | Depth camera or USB device |

> Verify voltage and polarity before connecting an XT30 power cable.
